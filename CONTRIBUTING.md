Contributing and Release instructions
====================================

FFmpeg/FFprobe binaries
-----------------------

To avoid tracking large binaries in the repository, `ffmpeg.exe` and `ffprobe.exe` are not stored in the main Git history. For releases, upload these executables as Release assets on GitHub and include checksums.

Steps to create a release with binaries:

1. Build the project and generate artifacts (zip, installer, etc.).
2. Go to the repository page -> Releases -> Draft a new release, or use the draft generated by the CI workflow.
3. Attach the following assets to the release:
   - `ffmpeg.exe`
   - `ffprobe.exe`
   - `StreamerPro.zip` or installer
4. In the release notes, include the SHA256 sums (found in `CHANGELOG.md`) and a link to `LICENSE-FFMPEG.txt`.

Verifying binaries locally
--------------------------
Use the provided script `tools/verify-ffmpeg.ps1` to verify local copies against the expected SHA256 checksums before uploading.

Git LFS alternative
-------------------
If you prefer to keep the binaries in the repository, configure Git LFS and migrate the files:

1. Install Git LFS: https://git-lfs.github.com/
2. Track binaries: `git lfs track "Streamer/ffmpeg.exe" "Streamer/ffprobe.exe"`
3. Migrate existing files: `git lfs migrate import --include="Streamer/ffmpeg.exe,Streamer/ffprobe.exe"`
4. Commit and push.
